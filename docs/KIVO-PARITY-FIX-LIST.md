# Kivo parity fix list

## Wallet / cash
- Deposit flow: improve network selection, address presentation, share/copy affordances and match Mango-style cash UX.
- Withdraw flow: keep gasless USDC transfer, improve network/recipient validation and result handling.
- Balance loading: keep cached USDC reads and avoid unnecessary RPC fan-out.

## Settings
- Make Security actionable with biometric wallet unlock.
- Make Notifications open device notification settings.
- Make Legal/Privacy open Kivo documentation/policy destination.
- Make Taxes export real local signed trade history.
- Make Help open support email.
- Make X open Kivo's X account.
- Make Telegram open Kivo's Telegram.
- Keep destructive logout/delete confirmation safe and explicit.

## Social / profiles
- Public usernames in group/channel messages are tappable.
- Tapping a username opens the person's public profile.
- Public profile provides Follow and Message actions.
- Preserve wallet-address identity underneath the social username.

## Deliberately excluded
- Google / Particle wallet path.
